# Nonpayment never automatically deletes Salon data

An unpaid Trial expiry or paid Subscription lapse moves the Salon to Read-Only Access without starting a deletion timer. Saluna retains the Salon's operational data while the account exists.

The Salon Owner may export the retained data or explicitly request account deletion through a separate owner-controlled flow. Subscription renewal restores operational access to the existing records. This avoids using data loss as payment pressure and prevents a missed renewal from destroying salon-owned history.
