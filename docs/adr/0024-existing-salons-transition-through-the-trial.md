# Existing salons transition through the Trial

Salons already active when billing launches will not retain permanent free access. Saluna will give them advance notice, then start the same full 30-day Trial used for newly activated Salons. An unpaid Salon becomes read-only when that Trial ends under ADR-0020.

This launch migration applies once to every already-active Salon even when one Salon Owner operates more than one. After launch, ADR-0020's one-Trial-per-owner rule applies normally.

This gives existing salons a defined transition period without creating a second permanent entitlement model that future pricing and access checks must preserve. Setup Salons remain outside the Trial until activation, as already defined.
