# Birthday outreach is manager-triggered

Birthday Follow-Ups offer call, SMS, and the existing Bale message action. Saluna does not send birthday messages automatically or add bulk campaigns, Telegram, or WhatsApp in this release.

SMS and Bale start from a short prefilled congratulations message that the manager may edit for the individual Client before confirming delivery. The v1 default text does not mention the Client's calculated age, although the complete Client Birth Date preserves that option for later personalization. No reusable salon message-template system is added.

Saluna does not require or store a separate birthday-outreach permission before enabling these manager-triggered actions. The manager confirms each server-sent message. This product decision does not establish whether a salon has satisfied any external legal or contractual obligation.
